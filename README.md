# Earthdawn Thermographic Vision

Module personnel Foundry VTT pour une vision thermique inspirée de l'infravision d'Earthdawn 4e.

> **État du dépôt : structure préparatoire.** Aucun module installable ni aucune version ZIP n'est publié à ce stade.

## Cible
- Foundry VTT v14
- Système Earthdawn 4e officiel (`ed4e`)
- Projet de développement associé : https://github.com/jdryannou-ux/Earthdawn-Infravision

## Structure
- `module.json` : manifeste Foundry, à la racine.
- `scripts/` : scripts JavaScript du module.
- `styles/` : feuilles de style CSS.
- `templates/` : modèles d'interface.
- `lang/` : fichiers de traduction.
- `assets/` : images, icônes et ressources.
- `docs/` : installation, configuration et tests.

## Import du contenu existant
Décompresser l'archive source sur l'ordinateur, puis déposer les fichiers dans les dossiers correspondants en conservant leur arborescence. Ne pas renommer les fichiers et ne pas remplacer un fichier existant sans vérification.

Le manifeste `module.json` doit être placé directement à la racine du dépôt. Le ZIP de distribution sera préparé seulement après vérification de la structure et du fonctionnement du module.
